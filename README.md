# The Cozy Book Café

## 1. Project Overview

The Cozy Book Café is a multi-page website created for the WEDE5020 Web Development (Introduction) project. The website represents a welcoming café where customers can enjoy books, coffee, light meals, and a comfortable reading environment.

The website is designed to be simple, user-friendly, responsive, and easy to navigate.

## 2. Goals and Objectives

- Introduce visitors to The Cozy Book Café and its services.
- Provide information about the café and its story.
- Display available books and café products.
- Show the café menu and prices.
- Allow visitors to submit an enquiry.
- Make contact and location information easy to find.
- Create a warm and welcoming online experience.
- Use responsive CSS so the website can be viewed on desktop, tablet, and mobile devices.

## 3. Current Analysis

The current Part 1 website is a five-page static HTML website consisting of Home, About Us, Books & Café/Products, Enquiry, and Contact pages. The pages contain relevant content, images, navigation links, forms, and semantic HTML elements.

## 7. Website Pages

### Home - `index.html`

Introduces The Cozy Book Café with a welcome message, navigation, café imagery, information about what the café offers, and a call-to-action. It also includes a photo gallery that opens in an accessible lightbox viewer.

### About Us - `about.html`

Provides information about the café, including its story, mission, vision, and team.

### Products - `products.html`

Displays books in an organised table and provides the café menu with food, drinks, descriptions, prices, and availability information. The featured book table is generated by JavaScript and can be searched by title or genre and filtered by genre.

### Enquiry - `enquiry.html`

Provides a form that visitors can use to make an enquiry about the café, books, food, or services. The form validates every field with inline error messages and shows a personalised response with a reference number after a valid submission.

### Contact - `contact.html`

Provides contact details, opening hours, branch information, and two embedded maps for the Rosebank and Sandton locations. A validated contact form prepares a message to the café, or sends it through a form service when `FORM_ENDPOINT` is configured.

## 21. Part 3 — Functionality and SEO

### JavaScript functionality
- Added `js_assets/script.js`, shared by all five HTML pages.
- The Books & Café page now builds the featured book table dynamically from a JavaScript data array.
- Added live title/genre search and a genre filter, with an accessible result count and no-results message.
- Added client-side validation and field-level browser validity feedback for the enquiry and contact forms.
- The enquiry form returns guidance based on the selected enquiry category. This is a front-end demonstration and does not store or transmit enquiries.
- The contact form validates the details and prepares a message addressed to `info@cozybookcafe.co.za` using the visitor's email application. The visitor must review and send the email; a `mailto:` form cannot send email silently or guarantee delivery.

### Search engine optimisation
- Added a unique descriptive title and meta description to every page.
- Added `aria-current="page"` to each page's active navigation link.
- Retained semantic headings, descriptive image alternative text, internal navigation and responsive image sources.
- Added `robots.txt` and `sitemap.xml` starter files. Before deployment, replace `https://YOUR-PUBLISHED-DOMAIN.example` in both files with the final public HTTPS URL.
- Kept map embeds lazy-loaded and added reduced-motion support.

### Form behaviour and sending email
- Both forms use `novalidate` and JavaScript validation: every invalid field shows its own inline error message directly under it (linked with `aria-describedby`, marked `aria-invalid`), errors clear as the visitor corrects them, and focus moves to the first problem.
- On success the Enquiry page shows a personalised response with a reference number and category-specific guidance.
- **Real email sending:** create a free form at https://formspree.io, copy the form endpoint (e.g. `https://formspree.io/f/xxxxxxx`) and paste it into the `FORM_ENDPOINT` constant at the top of the forms section in `js_assets/script.js`. The forms then POST the data, show a "Sending…" state and report success or failure clearly.
- If `FORM_ENDPOINT` is empty, the Contact form falls back to preparing an email in the visitor's own email application (`mailto:`).

### Gallery lightbox and keywords (Part 3 completion)
- Added a Gallery section to the Home page with four photos. Selecting a photo opens a full-size lightbox with Previous, Next and Close buttons, arrow-key and Escape support, click-outside-to-close, focus trapping and captions.
- Added a relevant `<meta name="keywords">` tag to every page.
- Renamed all images with descriptive, keyword-rich file names (for example `cozy-book-cafe-interior.png`) and updated every reference and `srcset`.
- Fixed a stray closing `</section>` on the Books & Café page and the enquiry type dropdown, which now defaults to the placeholder so validation works.
